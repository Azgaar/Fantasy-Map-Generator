Fantasia is an open-source tool for creating, editing, and visualizing fantasy maps. It is a fork of Azgaar's Fantasy Map Generator. You may use auto-generated maps as they are, edit them, or create a new map from scratch. Check out the Quick start, Q&A, Video tutorial, and hotkeys for guidance.

The created maps can be used freely, including for commercial purposes. For upstream community resources, visit the Azgaar FMG Discord server and Reddit community.

Fantasia is under active development. Track changes and report issues on the Fantasia GitHub repository. The original FMG project and its historical documentation remain available from Azgaar.
