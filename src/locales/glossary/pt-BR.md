# Portuguese (Brazil) glossary

Terms every `pt-BR.json` string uses the same way. Rules for all catalogs are in
[docs/architecture/translation.md](../../../docs/architecture/translation.md).

## Style

- Address the user with **você** only in questions and messages: “Tem certeza de que deseja remover o povoado?”.
  Buttons, menu items and tooltips take the infinitive or the imperative: “Salvar mapa”, “Clique para editar o povoado”.
- Use Brazilian spelling and words: arquivo, tela, mouse, excluir, salvar, configurações, equipe, fato.
- Dialog titles and editor names are noun phrases: “Editor de culturas”, “Visão geral dos rios”.
- Capitalize only the first word of a label: “Editor de culturas”, not “Editor de Culturas”.
- **Estado** (the polity) is lowercase, as in “estado”; it is read from context like “Editor de estados”.
- Keys keep their keyboard names: Ctrl, Shift, Alt, Enter, Esc, Espaço.
- Brand and product names stay: Fantasy Map Generator, Azgaar, Armoria, Dropbox, Discord, Google, Patreon.
- Months and days are lowercase: “janeiro”, “setembro”.
- Quotes are “ ” and no straight double quotes appear in visible text.
