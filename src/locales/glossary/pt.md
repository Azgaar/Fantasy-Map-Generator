# Portuguese (Portugal) glossary

Terms every `pt.json` string uses the same way. Rules for all catalogs are in
[docs/architecture/translation.md](../../../docs/architecture/translation.md).

## Style

- Address the user with **você** only in questions and messages: “Tem a certeza de que pretende eliminar a povoação?”.
  Buttons, menu items and tooltips take the infinitive or the imperative: “Guardar o mapa”, “Clique para editar a povoação”.
- Use European Portuguese spelling and words: ficheiro, ecrã, rato, eliminar, guardar, definições, equipa, facto.
- Dialog titles and editor names are noun phrases: “Editor de culturas”, “Visão geral dos rios”.
- Capitalize only the first word of a label: “Editor de culturas”, not “Editor de Culturas”.
- **Estado** (the polity) is always capitalized, so it is never read as “state, condition”.
- Keys keep their keyboard names: Ctrl, Shift, Alt, Enter, Esc, Eliminar for Delete.
- Brand and product names stay: Fantasy Map Generator, Azgaar, Armoria, Dropbox, Discord, Google.
- Dates and months are lowercase: “janeiro”, “setembro”.
