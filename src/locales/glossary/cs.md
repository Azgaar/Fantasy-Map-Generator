# Czech glossary

Terms every `cs.json` string uses the same way. Rules for all catalogs are in
[docs/architecture/translation.md](../../../docs/architecture/translation.md).

## Style

- Address the user with **ty** only where unavoidable; prefer impersonal wording: “Opravdu smazat sídlo?”, “Kliknutím upravíte sídlo”.
- Buttons and menu items take the infinitive or a noun: “Uložit mapu”, “Smazat vše”, “Načtení”.
- Tooltips use “Kliknutím …” or the infinitive: “Kliknutím seřadíte podle …”, “Kliknutím změníte značku”.
- Dialog titles and editor names are noun phrases: “Editor kultur”, “Přehled řek”.
- Quotes are „…“. Capitalize only the first word of a label: “Editor kultur”, not “Editor Kultur”.
- Keys keep their keyboard names: Ctrl, Shift, Alt, Delete, Enter, Esc; Space is “Mezerník”.
  Key hints use a dash: “Esc — zrušit”, “Shift + klik — …”.
- Shorten only where the label must fit: “Prům. cena”, “Vel. tipů”.
- Link text inserted into a sentence takes the case the sentence needs; prefer wording that keeps a brand link in the nominative.
- Azgaar is declined: “Azgaarův asistent”, “Napište Azgaarovi”.
- Brand and product names stay: FMG, Armoria, Dropbox, Discord, Google.
- The product names are translated: “Generátor fantasy map”, in full “Azgaarův generátor fantasy map”; the assistant is “Azgaarův asistent”.
