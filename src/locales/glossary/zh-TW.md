# Chinese (Traditional, Taiwan) glossary

Terms every `zh-TW.json` string uses the same way. Rules for all catalogs are in
[docs/architecture/translation.md](../../../docs/architecture/translation.md). The Simplified
catalog's terms are in [zh.md](zh.md); this file lists where Taiwan usage differs.

## Style

- Follow the same style as `zh.md`: short verbs on buttons, full-width punctuation, curly quotes “ ”.
- Use Taiwan wording, not a mechanical conversion: 軟體, 資訊, 網路, 預設, 設定, 檔案, 滑鼠, 伺服器.
- Put a space between Chinese and a Latin word or number: “API 金鑰”, “3 個城鎮”.
- Brand and product names stay Latin. The product is “Azgaar 的奇幻地圖生成器”.

## Differences from Simplified

| English                      | Simplified (zh) | Traditional (zh-TW)          |
| ---------------------------- | --------------- | ---------------------------- |
| undo / redo                  | 撤销 / 重做     | 復原 / 重做                  |
| apply                        | 应用            | 套用                         |
| add (a new item)             | 添加            | 新增                         |
| current                      | 当前            | 目前                         |
| lost (data)                  | 丢失            | 遺失                         |
| template                     | 模板            | 範本                         |
| rendering                    | 渲染            | 算繪                         |
| drag                         | 拖动            | 拖曳                         |
| scroll                       | 滚动            | 捲動                         |
| font                         | 字体            | 字型                         |
| type (kind)                  | 类型 / 型别     | 類型                         |
| click                        | 点击            | 點選                         |
| support (verb)               | 支持            | 支援                         |
| text (plain)                 | 文本            | 文字; plain text file: 純文字檔 |
| account                      | 账户            | 帳戶                         |
| information                  | 信息            | 資訊                         |
| software                     | 软件            | 軟體                         |
| procedure / engagement       | 程序            | 交戰進程 (procedure: 程序)   |
| map                          | 地图            | 地圖                         |

Terms that match Simplified in Taiwan too (生成, 更改, 配置, 文件 for documentation, 單元格 for cell)
are kept as in `zh.md`.
