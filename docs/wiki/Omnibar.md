The **Omnibar** searches the map and runs commands from one place. Press <kbd>Space</kbd> with the map focused, or click **Search** at the bottom of the menu.

## Find something on the map

Type part of a name. Results include states, provinces, burgs, cultures, religions, biomes, goods, rivers, routes, markers, geographical features, zones, journeys, markets, regiments and labels. Notes are searched too: matching text appears in the result, so you can find a place from its description.

Select a result to open its editor. Labels and entities without an editor are revealed on the map instead: the needed layers are enabled, and the view zooms to and highlights the result.

Use <kbd>↑</kbd> and <kbd>↓</kbd> to select a result, <kbd>Enter</kbd> to open it, and <kbd>Escape</kbd> to close the Omnibar. You can also click a result.

## Run a command

Commands are marked with **>**. Type a tool, layer or action name, or start the query with **>** to show commands only. For example:

- `> features` finds the Geographical Features Overview.
- `> wrap` finds the Wrap Tool.
- `> heightmap` finds heightmap-related actions.

Commands can open editors, toggle layers, create map objects, regenerate data, save, load and export. Read the action's name before selecting it: a regeneration command changes the map. Typing a question also offers **Ask AI**, which opens the Azgaar Assistant, where you can enter your question.

The empty search shows recently used commands. The last ten are remembered in your browser; map search results are not kept in that history.

## When shortcuts are unavailable

The Space shortcut leaves typing and focused controls alone. While a brush owns Space for panning, it continues to pan. Generate or load a map before using map actions, exit customization mode, and switch from the 3D scene to the 2D map if the Omnibar asks you to do so.

See [Hotkeys](https://github.com/Azgaar/Fantasy-Map-Generator/wiki/Hotkeys) for direct shortcuts to tools and layers.
