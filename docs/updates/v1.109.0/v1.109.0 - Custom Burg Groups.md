# Azgaar's Fantasy Map Generator v1.109.0: Custom Burg Groups

Fantasy Map Generator is updated up to version 1.109.0. It was a long road to the update, both due to long periods on inactivity and dozens of code issues to be fixed. The new version is compatible with previous versions, loaded save files will be auto-updated.

### Custom Burg Groups

Create custom groups for your cities and towns, each with their own icons and styling. This new feature gives you more control over how settlements are organized and displayed on your map.

All 12 style presets have been refreshed with new burg styling options and visual improvements.

**What you'll see:**

- Burg groups editor screen is now available from Burgs Overview screen
- Your group settings are saved automatically between sessions
- Integration between burg groups and other map features

**What you can do:**

- Organize cities and towns into custom groups (e.g., "Major Cities", "Port Towns", "Religious Sites", "Trading Posts")
- Choose different icons out of provided set for each group to make them visually distinct (in _Style_)
- Set preview generator for each group (e.g., "Watabou City", "Watabou Village", "Watabou Dwelling")
- Set automatic grouping rules based on:

  - Population size (minimum, maximum, or percentile)
  - Location (biomes, states, cultures, religions)
  - Special features (ports, capitals, temples, etc.)

The changes are backward-compatible. Your existing maps will be automatically updated to support the new features when you load them. **You may see some changes** in your burg groups and icons that would require **manual adjustment**.

### 3D Mode Enhancements

The 3D view has been slightly improved with new lighting options and better rendering.

**What you'll see:**

- Use time-of-day presets for quick lighting changes:

  - **Dawn** - Warm morning light with orange skies
  - **Noon** - Bright daylight with clear blue skies
  - **Evening** - Golden sunset lighting
  - **Night** - Dark atmospheric lighting
- See improved mesh quality
- Navigate 3D maps with improved controls
- 3D labels view improvements
