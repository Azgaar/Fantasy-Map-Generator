# Azgaar's Fantasy Map Generator v1.73.2: Pre-defined Heightmaps

Sometimes users ask _"where can I find a seed to generate a map or Earth"_? And while it's possible to import an image and convert it to heightmap, it can be pretty unobvious that there is a feature lie that.

Generally it doesn't have to to be that complex. We can simply build-in some pre-defined heightmaps right into the generator. It can work the same as way templates work: select a heightmap and create a new map. So I decided to give it a chance.

As I'm preparing these images on my own, I know exactly how to convert then into a heightmap. The only issue is aspect ratio, but for now we can just assume most screens are 2:1 or something like that. Otherwise heightmaps will be screwed.

Adding a gallery of the already added heightmaps to the post. All heightmaps are created using publicly available real-world data using [tangrams.github.io](http://tangrams.github.io).
