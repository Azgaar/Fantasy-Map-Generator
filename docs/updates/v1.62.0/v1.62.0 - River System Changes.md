# Azgaar's Fantasy Map Generator v1.62.0: River System Changes

Here is a small update changing the way the map is prepared for river generation. There were a lot of issues with maps having too many land depressions. _Depressions_ are cells that are lower that all cells around and hence precipitation water cannot find its way to ocean. In real world most of depressions are resolved by millions of years of erosion, so in FMG there is a process simulating it.

The depressiong are getting resolved by incremental depressed cells elevation until most of them are resolved, i.e. water has downhill path to the ocean. Now algorithm a is a bit smarted and don't try to elevate cells that are too depressed. Instead lakes are getting added there. As a result the map is not getting smoothed so much.
