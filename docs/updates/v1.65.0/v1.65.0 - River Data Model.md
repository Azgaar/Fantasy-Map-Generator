# Azgaar's Fantasy Map Generator v1.65.0: River Data Model

Relatively small update that took me about a week of hard work. Most of the time was spent of code refactoring, so not visible for users. Now river generation is separated from river rendering and the code is much more cleaner. River course can be restored from the data, so the issue we had on river edit is now resolved. It also made river edit easier, but not so flexible as it was.

I have also added a new river creation mode: select rivers cells and system with create a river there. No mater what the heights are, custom rivers are responsibility of users, so you need to find plausible courses manually.

Old mode of "click to add" is still supported. Now it should work better with existing river system.

Main changes:

- Refactoring river rendering
- River data is now stored in object, not svg
- Keep river course on edit
- Ability to add river selecting its cells
