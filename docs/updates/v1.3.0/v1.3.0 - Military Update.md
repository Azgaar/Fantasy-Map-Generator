# Azgaar's Fantasy Map Generator v1.3.0: Military Update

Hello! Here is the first major FMG update in 2020. It is almost completely devoted to military forces and hence call be called a **Military update** ⚔️.

Now each state has military forces generated based on state population, land possessions and cultural specific, diplomacy and other factors. Generation is cell-based, but aggregated to Regiments level for usability purposes.

Generation rules, unit types and regiments themselves are editable and customizable. You can add fantasy, modern or ancient units, change parameters and re-generate military to let generator automatically recreate regiments. Changes specific to state or culture can be done manually on regiments level.

**Main features:**

- Military Forces generation
- Military Forces overview screen
- Regiments overview screen
- Military Units editor
- Regiments editor
