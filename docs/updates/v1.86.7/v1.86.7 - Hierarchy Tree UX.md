# Azgaar's Fantasy Map Generator v1.86.7: Hierarchy Tree UX

[The previous update](https://www.patreon.com/posts/67435076) was fun and all, but it got some reasonable critique as it was really hard to work with big hierarchy trees. I decided to spend a week more to make hierarchy trees actually usable and enjoyable.

As each node can have multiple parents (origins) now, there should be additional UI elements to simplify the work with tree and make more obvious how it works. Main changes are listed below:

- drag and zoom behaviour (zoom out to see the whole tree if required)
- click on node to open origins edit menu
- on edit: click on origin to remove it
- on edit: select origins menu, select primary origin with radio button, secondary origins with checkboxes
- sort origins to get nodes with more shared secondary links closer to each other
- fancy tree update animation
- technical: move hierarchy tree to its own generic dynamically loaded module

Hierarchy tree is still available for cultures and religions. But due to the last change listed above it is very easy to add tree view for other elements when needed.
