# Azgaar's Fantasy Map Generator v1.96.0: Ocean Heightmap

Introducing the next update to the Fantasy Map Generaror. In this release we've addressed a series of pesky bugs while also introducing two enhancements to enrich your experience.

**Ocean heightmap rendering**: Dive deeper into customization with the capability to render ocean heights. Now, within the Style menu, navigate to Heightmap -> oceanHeights and check the "Render ocean cells" box.

While this feature empowers you to add depth and realism to your oceanic landscapes, it's worth noting that it's disabled by default as it may not be suitable for all maps.

Ocean heightmap rendering supports all the same features as the land heightmap.

**Revamped styling options for the Scale bar.** Scale bar styling options are moved from the Units editor to Style -> Scale bar. This addition streamlines the customization process and adds new styling features to ensure Scale bar complements your map aesthetics.

Don't hesitate to let us know if you encounter any issues or have suggestions for further improvements.
