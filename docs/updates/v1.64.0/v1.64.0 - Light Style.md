# Azgaar's Fantasy Map Generator v1.64.0: Light Style

Yesterday's [Watercolor style](https://www.patreon.com/posts/53535277) is good, but what about adding one more style, this time more usable in real projects, but still showing some interesting techniques. This time introducing the **Light** style set. It uses both new state borders style and features available for a long period of time, but still unknown for most of the users, e.g. the _turbulence_ filter or heightmap _terracing_.
