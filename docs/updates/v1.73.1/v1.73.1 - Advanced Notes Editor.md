# Azgaar's Fantasy Map Generator v1.73.1: Advanced Notes Editor

One of the most requested features of the latest months was an ability to edit the link to the [One page dungeon](https://watabou.github.io/one-page-dungeon) generator by Watabou. A small request caused pretty significant changes.

I was not happy with the Notes Editor we had before and decided to replace it with a more advanced tool. The replacement tool should still be a WYSIWYG html editor, but has to be simpler to use, support _iframe_ and _image_ elements editing (_iframe_ is used for the _One page dungeon_ preview) and rich text formatting.

As we are using dynamic import 3rd party scripts now, i.e. load them when required rather then on startup, there is no significant size limitation and I was able to select from a good variety of pre-made open-source solutions.
